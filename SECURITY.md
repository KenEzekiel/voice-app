# Security policy

This is an experimental desktop-control preview, not a security-reviewed production
assistant. Only the current development version is maintained. See [PRIVACY.md](PRIVACY.md)
for desktop authority, data flow and known approval limitations.

Do not put credentials, private transcripts, screenshots or exploit details in
public issues. Use GitHub's private vulnerability reporting for this repository
if the Security tab offers “Report a vulnerability”. If it is unavailable, ask
for a private reporting channel without disclosing the vulnerability. No response
SLA or bug bounty is offered.

Reports should describe the affected revision, trust boundary, minimum safe
reproduction with disposable data, and observed result. Do not test against
other accounts, private data, deployed services or irreversible actions.
